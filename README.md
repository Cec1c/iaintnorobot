# I Ain't No Robot

一个 AstrBot 多群插话插件原型：让机器人低频、简短地参与群聊，偶尔像群友一样接一句。

插件的消息、配置、LLM 调用和发送均使用 AstrBot，群聊上下文与摘要保存在插件数据目录的 SQLite 中。

## 安装与启用

将本目录放到 AstrBot 的 `data/plugins/astrbot_plugin_i_aint_no_robot`，在 WebUI 重载插件，再将目标群加入“已添加群聊”并启用。插件会补齐已知平台会话，每个群分别计算触发条件和发言冷却。

完整配置见[部署说明](docs/deployment.md)。

## 它会在什么时候说话

- **主动插话。** 后台定期检查群聊，优先寻找可以附和或轻聊的话题；没有合适话题时，才以较低概率自创一句。
- **延迟后再判断。** 触发后随机等待几秒到两分钟，重新读取最新消息，再决定是否发言。条件不满足或概率未命中时，短暂等待后继续检查。
- **回应艾特。** 直接艾特会交给插件生成短回复，空白艾特也由插件接管；命中放行规则的命令，如 `/在线`、`重启服务器`，交给其他插件处理。
- **接续对话。** 机器人刚发言后，群友接短句，或提到机器人、插件、默认回复时，插件会判断是否是在对它说话。

## 记忆与表达

SQLite 保存短文本上下文、压缩摘要和群内黑话解释。黑话含义不确定时暂缓使用，也可通过 WebUI 指定内线 QQ，询问黑话、图片或游戏机制相关内容。

群聊发言与内线私信由 LLM 生成，程序负责节流、记忆和过滤。回复限制为短句，并过滤 Markdown、客服腔和常见 AI 套话；最近想表达的态度也会作为后续回复的线索。

当前原型采用群友角色设定：被称为 AI 时可忽略、调侃或短回应，且不承认 AI 身份。被问到账号插件触发时，倾向于用“我只是拿这个号说话”等短句带过。

## 指令

```text
/iar status   查看状态
/iar on       开启当前群
/iar off      关闭当前群
/iar addgroup 把当前群加入并启用
/iar groups   查看已添加群聊
/iar say      强制尝试生成一句，方便测试
/iar summary  手动刷新群语境记忆
/iar slang    查看黑话记忆
/iar learn    手动扫描黑话
/iar reset    清空当前群的插件记忆
```
